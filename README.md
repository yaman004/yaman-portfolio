# Yaman Choudhary Portfolio v2

This version intentionally follows the current open-source developer-portfolio direction seen in popular GitHub templates: restrained typography, light/dark neutral surfaces, one strong accent color, bento/project cards, timelines, subtle motion, and minimal glass effects.

Reference research:
- Gothsec/dark-minimal — 261 stars when checked
- mayankagarwal09/dev-portfolio — 397 stars when checked
- metal-oopa/personal-portfolio — 85 stars when checked

The design is original and does not copy those repositories.

## Run
Open `index.html`, or use VS Code Live Server.

## Deploy
Drag the folder to Netlify Drop, or upload the files to GitHub and import the repository into Vercel.
